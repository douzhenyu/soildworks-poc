# 图审 · 本地数控审图工作台

运行地址：<http://127.0.0.1:8765>

## 使用

1. 在安装 SolidWorks 的这台 Windows 电脑运行 `启动审图工作台.cmd`，保持服务运行。
2. 浏览器打开上述地址，上传 ZIP。工程图 `.SLDDRW` 和配套 `.SLDPRT` / `.SLDASM` 应保留原目录关系。
3. 等待解压、逐页提取信息和 PDF 转换。在目录选择图纸，检查图框、尺寸线、文字与页数。
4. 选择规则，点击“确认图纸，开始审图”。转换完成不会自行开始审核。
5. 点击右侧问题卡片，定位到对应页和标记。支持缩放、逐页切换、单份 PDF 与整批审核包下载。

本机已验证两份实际图纸的 ZIP 上传 → SolidWorks API → A3/A4 共3页 PDF → 用户确认 → 规则审核 → 标注 PDF 下载。

## 依赖与运行

- Windows、SolidWorks 2025、本机 Microsoft Print to PDF 打印机。
- Python 3.10+，依赖 `pymupdf`。`requirements.txt` 可用于其他环境安装。
- 当前桥接 DLL 路径为 `D:/SOLIDWORKS Corp/SOLIDWORKS/`；安装路径不同时修改 `bridge/*.ps1` 中的 DLL 路径。
- 服务仅监听 `127.0.0.1`，适用于本机单人工作站。不要直接对公网开放。
- 文件存放在 `data/<任务ID>/`，含原 ZIP、解压副本、逐页 API 数据、PDF、日志、审核问题和状态。重启后可查看历史任务；中断任务标记失败。
- 同一时间串行调用 SolidWorks，避免并行 COM 操作干扰。转换单文件超时300秒。
- 原上传文件保留在 ZIP 中；桥接按只读打开工程图，不保存源 drawing 修改。打印设置在调用后恢复。
- PDF 原纸张尺寸按当前图纸尺寸匹配 A3/A4，按100%打印；其他纸张或不同纸张混合的多页文档未验证，需检查预览，不能默认完整。

## 审图 Agent 与图纸证据

右上角的“模型设置”可选择 Codex CLI 或自定义模型服务。自定义服务需兼容 Chat Completions，且模型需同时支持图片输入和函数工具调用。配置保存在本机的 `data/model-settings.json`，密钥以明文写入此文件。每批审核启动时读取当时的设置。Codex CLI 使用已登录的 `codex exec`，从 PATH 或桌面版安装目录查找。

- 转换时在任务目录 `evidence/<文件ID>.json` 写入每份图纸的 API 证据。工作台“↓ JSON”及审核包均提供下载。坐标从 PDF 左上角开始，提供 PDF 点坐标和归一化标注框。部分对象只有定位点或模型坐标。
- 证据 JSON 的 `dimension.constraintEvidence` 提供尺寸方向、经图面界线核实的端点、关联对象、参考显示状态及从动状态。视图用 `modelKey` 区分引用模型和配置。中心线关联及 `modelEnvelope` 分别提供定位基准候选和模型外形范围。
- Agent 加载 `skills/drawing-review/SKILL.md`，通过 `read_drawing_evidence` 按页和元素类型查询当前图纸，并对照全套页面图像。Codex CLI 通过任务级 MCP 使用该工具，自定义模型通过函数调用使用同一查询。
- 每项选中规则返回综合结论，右侧同时显示规则引擎证据和 Agent 发现。局部结论可引用同页的元素编号来定位 PDF 标注。执行失败会显示原因。
- 页面图像、提示、CLI 日志和校验结果位于 `vision/<文件ID>/`。可用 `CODEX_VISION_MODEL` 指定 CLI 模型，`CODEX_CLI_PATH` 指定可执行文件。图纸图像及 Agent 查阅的证据会传给配置的模型服务。

## 同名工程图与失败重试

SolidWorks错误65536表示已有同名文档打开。程序在每批任务下创建唯一名称的CAD工作副本，并通过SolidWorks API重定向包内模型引用，保留原ZIP和解压原件，不关闭用户已有文档。忽略 `~$` 锁文件。缺失的外部/历史引用会写入 `cad-prepare.log`，相关几何完整性需复核；模型同名歧义则停止准备。

点击“重试失败图纸”可仅重试失败的文件，成功的PDF保留。补齐转换后回到待确认，需再次确认后审图。已完成任务可以点击“重新审图”，使用当前规则与Codex CLI重新审核。

## 规则覆盖

- 规则引擎检查模板内框和明细栏与技术要求文字的交叠、悬空尺寸、已知单位与词项、等距总尺寸参考括号、明细栏属性链接、模板文字、受控水印文字和标准引用。
- 文字交叠及未解析属性链接输出待复核。重复特征数量、尺寸完整性、封闭尺寸链、签名与图片水印仍需结合视觉或人工复核。
- R12没有外部标准有效性数据源，只显示“引用标准版本待核验”。不依赖任何企业协作平台。
- 所有文件均使用本次上传后实际提取的数据，不按文件名复用历史问题。

## 验证

`python -m unittest discover -s tests -v`：ZIP目录穿越、符号链接和重复路径检查、实际提取数据的规则检查、Codex CLI响应坐标与规则约束校验。

`test-e2e.py`：本工作区样本的真实SolidWorks端到端测试（会上传并生成测试任务）。

`test-browser.cjs`：使用已安装 Edge 的无头浏览器验证前端；不控制 SolidWorks 界面。

## 文件结构

- `server.py`：本地 HTTP 服务、上传、任务队列、规则引擎、视觉接口和 PDF 标注。
- `web/`：无构建依赖的 HTML/CSS/JavaScript 前端。
- `bridge/`：已验证的 SolidWorks 强类型 API 提取与打印脚本。
- `data/`：本地任务数据（不应提交到源码仓库）。
